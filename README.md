# 突发限价预案执行台（油品价格维护扩展）

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 规则冒烟测试：`npx esbuild scripts/smoke.test.ts --bundle --platform=node --format=esm --outfile=/tmp/smoke.mjs && node /tmp/smoke.mjs`

## 业务闭环

1. **预案登记**：区域 + 油品 + 限价上限 + 生效窗口（起止时间）+ 站点等级；可按区域/等级全量覆盖，或显式勾选站点。
2. **整批判定**：同一批次内或与已登记未解除预案之间，同区域同油品的生效窗口不得交叠；等级不符（勾选站点不在预案等级内）、限价超过监管指导价上限等，任一行存在冲突则**整批只保留草稿**，并逐行标明冲突原因。
3. **生效冻结**：模拟时钟进入窗口时预案自动生效，对覆盖站点逐站冻结挂牌价（高于限价压到限价）并生成价签快照，同时记录生效前基线版本。
4. **站点执行**：站点逐站上报执行状态（未上报 / 执行中 / 已完成 / 异常），回传价签拍照价格，系统自动与冻结价核对（未回传 / 一致 / 不一致）。
5. **关窗铁律**：窗口到期后，任一站执行未完成、价签未回传或与冻结价不一致，窗口不得关闭；冻结期调价单超限或价签未核验一致时直接拒单，挂牌价不动。
6. **解除回落**：条件全部满足后解除预案，挂牌价按各站冻结前基线版本回落。
7. **版本一致**：预案登记 / 冻结 / 限价内调价 / 解除回落 / 常规调价全部写入只增不改的版本流水；数据保存在 localStorage，刷新后预案、执行、价签、版本完全一致。

## 分层结构

- `src/domain/types.ts` — 领域模型
- `src/domain/constants.ts` — 站点主数据、指导价常量、种子状态（数据）
- `src/domain/rules.ts` — 纯函数判定：窗口交叠、整批校验、冻结价、关窗条件、调价单核验（判定）
- `src/store/storage.ts` — localStorage 读写（存储）
- `src/store/console.ts` — Pinia store，编排数据 + 判定 + 存储
- `src/components/*Page.vue`、`src/App.vue` — 登记 / 执行台 / 调价单 / 版本快照四个页面（页面）

数据、判定、存储与页面互不耦合，规则可脱离浏览器单测，便于后续替换为接口、增加权限或地图能力。
